RAASTA
Smart Bus Route Finder

Know Your Route. Know Your Way.

Raasta is a web platform that helps people find
public transport routes between two locations.

Built initially for Karachi, Pakistan.
Designed for expansion to other cities.

## Features

- From → To route search
- Bus route information
- Bus stops
- Roads traveled
- Route map
- Step-by-step journey
- Transfer information
- Landmark search
- English / Urdu support
- Responsive design

## Tech Stack

Frontend
- Next.js
- React
- Material UI

Backend
- Node.js
- Express.js

Database
- MongoDB
- Mongoose

Maps
- OpenStreetMap / Map provider
